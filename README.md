# Jyutly
Cantonese tone coach for heritage learners.

- `packages/tone-engine` – pure TS: YIN pitch tracking, speaker-range normalization, DTW alignment, per-syllable tone scoring + feedback (`npm test -w @jyutly/tone-engine`).
- Planned: `apps/mobile` (Expo), `content/` (words + reference contours), `tools/build-reference`, `supabase/`.
